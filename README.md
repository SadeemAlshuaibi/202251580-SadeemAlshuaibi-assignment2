## Personal Portfolio Website – Assignment 3

## Project Description

This project is a personal portfolio website developed as part of Assignment 3. It builds on previous assignments by adding advanced functionality, external API integration, improved logic, and better state management.

The website includes sections such as About, Skills, Projects, GitHub, and Contact, and demonstrates more advanced web development concepts and interactive features.

## Features

* 🌗 Theme toggle (dark/light mode) using localStorage
* 🔍 Live project search and filtering
* 🔄 Project sorting based on difficulty level
* 👤 Visitor name storage with personalized greeting
* ⏱ Time-on-site counter
* 📡 GitHub API integration (dynamic repositories display)
* ⚠️ API error handling with user-friendly messages
* ✨ Dynamic motivational quotes (button interaction)
* 📩 Contact form with validation and success message
* 📭 Empty state message ("No projects found")
* 🎬 Smooth animations and scroll reveal effects

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* GitHub REST API
